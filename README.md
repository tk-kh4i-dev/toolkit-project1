# System Toolkit

A modular, lightweight diagnostic and maintenance toolkit for Windows, written in PowerShell and Python.

## Features
* **System Diagnostics**: Real-time hardware monitoring (CPU, RAM, Disk).
* **Disk Management**: Automated cleanup utilities.
* **Network Scanner**: Integrated network diagnostic tools.
* **Modular Design**: Easy to extend by adding new scripts to the `/src` directory.

## Usage
1. Open PowerShell.
2. Run `./toolbox.ps1`.
3. Use the menu to select your desired diagnostic or maintenance task.
4. You can find more advanced/other versions of the scripts inside `/src`, this toolkit file only include the tools that I think you need.

## Requirements
* PowerShell 5.1+
* Python 3.x 
* Dependencies: Ensure `psutil` and `cpuinfo` installed, you can get it via Powershell using this command: `pip install psutil py-cpuinfo`
